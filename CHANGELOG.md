# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-12: Initial open-source release

### Added
- 52-page pitwall UI kit: timing tower, driver stack, track canvas, radio/strategy column and stint ticker.
- Content-only in-app navigation (`js/spa.js`) with a terminal-style loader, `pushState`, back/forward, preserved driver-stack scroll and a `file://` fallback.
- Fuel and energy timeline chart with axes, legend, stint bands, pit markers, a fuel-save window, a "now" marker and a projection.
- `css/responsive.css` with 390/768/1280 layouts, day-theme chrome and the loader.
- Text-safe accent tokens (`--ax-*-t`) for night and day.
- QA tooling (`qa/`) and a data normaliser (`tools/normalize_data.py`).
- README, docs, screenshots, cover and MIT license.

### Fixed
- Contrast: 0 text runs below 4.5:1 in either theme (driver codes, gauges, active filters, muted text, CRIT badge, OP avatar, delta/tyre lines).
- The timing tower shows P1–P8 and the ✉ action at every width, and the legend/filters no longer cover the track at 390.
- Data: every lap equals the sum of its sectors, stint best ≤ average, and no race lap on any page beats the race best 1:22.721 (KAI); only labelled qualifying (Q1–Q3) and circuit-record times are faster. Driver-detail stint history renders from `AX_DATA`. `qa/audit.py` scans every page for laps faster than the race best.
- Track canvas: sector labels sit outside the racing line, car numbers inside, and boxed cars park in the pit lane, so no labels overlap at any width (`qa/labels.js`).
- Telemetry and analytics sparks have value axes, lap axes, labels and the current value, drawn from the demo data.
- Fuel & energy: removed the duplicated KPI row under the chart, and the pit-stop labels sit above the plot instead of on the fuel lines.
- `puppeteer-core` is a devDependency, so `npm install && npm run qa` works in a fresh clone.
- Lap data: the race is on lap 38/58, so `laps` holds laps 1–38 only (373 laps, all ten cars, generated by `tools/derive.py`), and each driver's lap 38 equals their timing-tower last lap with matching sectors (VEX 1:24.697).
- Spark labels are collision-aware (title and value stack on narrow rails, y-ticks keep a gap); `qa/sparks.js` checks every spark at every width.
- Car-number labels avoid the start/finish bar and its label; `qa/labels.js` includes them.
- `package-lock.json` is committed, so `npm ci` works.
- Cover: the energy timeline card is captured whole (full x-axis, legend) and fitted to its frame; `qa/cover.js` fails any mockup image cropped by its frame.
- Removed repeated stat cards (analytics, weather-track, car-detail, circuit-detail, driver-detail, stint-detail, strategy-sim, tire-set-detail); `qa/dupes.js` sweeps every page for stat labels repeated across card rows.
- Weather number book: one wind reading (12 kts, Tail S1), one track status and one rain cell per page, checked by `qa/audit.py`. Strategy-sim no longer shows two different risk ratings.
- Number book: one Mounted tyre set per car on the driver's current compound, one Active stint per driver, strategy compound sequences that match each car's stint and current tyre (#11 M-H-S-M, undercut L40 to MEDIUM), session-detail cards describe the live Race, strategy-sim risk matches the locked plan, and sector-map purple sectors come from the tower. `tools/sync_baked.py` re-renders every baked tyre/stint copy from `AX_DATA`.
- `qa/audit.py` cross-checks sessions, plans, tyre sets, stints, driver rows and global stat cards on every page against `AX_DATA`; `qa/dupes.js` also catches values and codes repeated inside card sub-fields.
